# Netflix Clone
This project is a Netflix clone that uses API integration to fetch and display dynamic data. I used TMDB API to retrieve movie and TV show details. The app consists of 4 pages, each showing different data sets with a UI styled similar to Netflix. The project showcases my skills in API integration and responsive UI design.
